# Excel Data Analysis – Sales Performance Dashboard

## Project Overview
This project focuses on analyzing sales performance using Microsoft Excel and PivotTables.

## Dataset
Global Superstore 2016 Dataset.

## Analysis Performed
1. Total Revenue Analysis
2. Sales by Category
3. Yearly Sales Trends
4. Region-wise Revenue Analysis

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Data Visualization
